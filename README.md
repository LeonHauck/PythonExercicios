# Exercicios propostos pelo Prof°Gustavo Guanabara - Curso de Python

## PythonExercicios

Este repositório contém a resolução dos exercícios práticos desenvolvidos durante o curso de Python do canal Curso em Vídeo, ministrado pelo professor Gustavo Guanabara.

## Sobre o Curso

O curso aborda os fundamentos da linguagem Python de forma prática. O conteúdo atual corresponde ao **Mundo 1**, que cobre desde a configuração do ambiente, operadores aritméticos, módulos, manipulação de texto até estruturas condicionais simples e compostas.

## Estrutura do Repositório

Os arquivos estão organizados de forma sequencial de acordo com o andamento do curso:

* **ex001.py ao ex027.py**: Exercícios práticos e desafios do Mundo 1 concluídos.

*O repositório será atualizado conforme o progresso nos próximos módulos do curso.*

## Como Executar os Exercícios

Para executar os códigos localmente, você precisa ter o Python instalado em sua máquina. Siga os passos abaixo:

1. Clone o repositório:
   ```bash
   git clone https://github.com
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd PythonExercicios
   ```

3. Execute o exercício desejado (exemplo com o exercício 1):
   ```bash
   python ex001.py
   ```
